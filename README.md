# 새벽 전 마지막 탄환

비 내리는 범죄도시에서 장부를 되찾는 **2D 횡스크롤 총격 로그라이크**입니다. 기존 단일 HTML 저장소를 Canvas + JavaScript 모듈 구조로 구현했습니다. 그래픽은 직접 설계한 도트 스프라이트와 320×180 Canvas로, 음악과 효과음은 Web Audio로 생성합니다. 로그인, 외부 이미지, CDN, API 키, 패키지 설치가 필요하지 않습니다.

## 실행

**단일 파일 실행:** `dist/index.html`을 내려받아 Chrome 또는 Edge에서 더블클릭해 여세요. CSS, 게임 코드, 그림과 음향 생성 코드가 모두 들어 있어 인터넷·서버·설치 없이 실행됩니다. **밤 속으로**를 누르면 게임과 오디오가 시작됩니다. 파일 이름을 바꿔도 동작합니다. 브라우저가 로컬 파일의 저장 기능을 제한하면 기록·설정 저장만 생략하고 게임은 실행합니다.

**정적 호스팅:** 공개 폴더에 `dist/index.html` 하나를 업로드하세요. Netlify·Cloudflare Pages 등에서 빌드를 설정한다면 명령은 `npm run build`, 게시 디렉터리는 `dist`입니다.

**GitHub Pages:** 이 저장소의 기존 Pages 게시 브랜치는 `master`입니다. 아래 명령은 최신 단일 HTML과 `.nojekyll`을 `origin/master`에 업로드합니다. 게시 브랜치의 다른 파일, 현재 개발 브랜치, 작업 파일과 Git 스테이징 영역은 유지하며 강제 푸시하지 않습니다. GitHub 저장소 쓰기 권한이 필요합니다.

```sh
npm run deploy
```

게임 주소는 `https://majingga0205-stack.github.io/-/`입니다. 기존 Pages 설정을 유지하고 [배포 실행 결과](https://github.com/majingga0205-stack/-/actions)에서 게시 완료를 확인합니다. 다른 저장소로 옮길 경우 [Pages 설정](https://github.com/majingga0205-stack/-/settings/pages)에서 **Deploy from a branch → master → / (root)**를 지정합니다. 다른 게시 브랜치를 사용하려면 `npm run deploy -- gh-pages`처럼 전달할 수 있습니다. 브랜치 업로드와 실제 게시 완료는 별도 단계입니다.

소스를 수정한 뒤 아래 명령으로 단일 파일을 다시 만들 수 있습니다. Node.js만 필요하며 `npm install`은 필요하지 않습니다.

```sh
npm run build
```

**개발용 실행:** 분리된 원본 파일로 개발하려면 Python 3이 있는 PC에서 이 저장소 폴더로 이동한 뒤 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저 주소창에 `http://localhost:8000`을 입력하고 **밤 속으로**를 누르세요. Node.js가 있다면 `npm run dev`로도 실행할 수 있습니다. 루트의 개발용 `index.html`은 ES 모듈을 사용하므로 HTTP 서버가 필요합니다. 더블클릭 실행과 배포에는 `dist/index.html`을 사용하세요.

## 조작

| 입력 | 동작 |
| --- | --- |
| A / D | 좌우 이동 |
| Space | 점프 — 코요테 타임 0.10초, 입력 버퍼 0.13초 |
| 마우스 이동 | 이동 방향과 독립적인 360도 조준 |
| 왼쪽 버튼 유지 | 사격 |
| R | 재장전 — 예비 탄약 무제한, 빈 탄창에서 사격하면 자동 재장전 |
| Shift | 회피 — 0.28초 이동, 첫 0.24초 무적, 기본 대기시간 1.25초 |
| Q | 두 무기 교체 |
| 오른쪽 버튼 유지 | 슬로모션 — 시간 배율 0.4, 초당 게이지 23 소모 |
| E | 근처 무기·치료 획득, 클리어한 방의 오른쪽 출구 이용 |
| Esc | 일시정지 / 계속하기 / 열린 안내창 닫기 |

무기는 최대 두 개입니다. 두 개를 가진 상태에서 새 무기를 주우면 **현재 무기를 바닥에 내려놓고** 교체합니다. 첫 방 입구에 보조 무기가 있습니다. 금속 엄폐물은 파괴할 수 없고 나무 상자는 공격하면 부서집니다. 점프해서 엄폐물 위를 노리거나 회피로 공격을 피하세요.

적 처치 시 집중 게이지 12를 회복합니다. 일반 방을 클리어하면 체력 18과 집중 25를 회복하고, 무작위 강화 세 개 중 하나를 선택합니다. 이후 무기를 확인하고 오른쪽 출구에서 E를 눌러 이동합니다.

## 도트 그래픽

장면은 320×180 픽셀 버퍼에서 그린 뒤 보간 없이 확대합니다. 주인공과 일반 적 5종·보스는 모자·후드·방탄복 등 실루엣이 다른 수작업 스프라이트이며, 총기 4종과 총구 화염도 도트로 그립니다. 비·네온·다층 배경·엄폐물·탄환은 같은 해상도로 표시합니다. 한국어 HUD와 상호작용 안내는 별도로 선명하게 표시합니다. 논리 좌표와 충돌 판정은 기존 1280×720을 유지하므로 360도 조준과 전투 수치는 달라지지 않습니다. 외부 이미지나 폰트를 내려받지 않습니다.

## 포함된 게임

- **뒷골목 → 지하철 → 조직 본부**, 총 9개 방. 일반 방은 각각 3차 공세, 마지막 방은 보스전입니다.
- 검증된 9개 지형 템플릿, 무작위 적 구성·배치·무기·강화. 연속된 지면과 도달 가능한 발판으로 구성합니다.
- 권총·리볼버·기관단총·산탄총. 피해, 연사, 탄 퍼짐, 탄창, 재장전, 반동, 사운드가 다릅니다. 산탄은 거리에 따라 약해집니다.
- 권총 사수·기관단총 사수·산탄총 집행자·돌진 칼잡이·중장갑 경호원. 모든 공격에 예고와 회복 시간이 있습니다.
- 보스 **백야**는 체력 50%에서 2단계로 전환합니다. 부채꼴 사격, 예고 후 집중 사격, 위치 이동을 사용합니다.
- 강화 14종: 회피 후 사격, 마지막 탄환, 처치 후 재장전, 관통, 슬로모션 정밀도, 교체 연사, 근거리 피해, 최대 체력, 탄창 확대, 총기 피해, 집중 회복, 집중 절약, 이동·회피, 처치 회복. 선택 화면과 강화 목록에 실제 수치·중첩 상한을 표시합니다.
- 시작·조작 안내·HUD·일시정지·설정·강화 선택·강화/무기 목록·사망·승리·즉시 재도전 화면.
- 음악/효과음 개별 볼륨, 화면 흔들림/섬광 강도 조절과 끄기. 설정과 최고 기록만 브라우저에 저장합니다.
- 120Hz 고정 시간 물리, 연속 선분 탄환 충돌, 관통 중복 피격 방지, 화면 밖 탄환/종료 이펙트 정리. 일시정지와 강화 선택 중 모든 전투 타이머가 멈춥니다.

## 검증

```sh
npm test
npm run test:run
```

- `npm test`: **52개 통과**. 이동/점프/회피, 모든 무기·강화, 적 예고와 보스 양 단계, 충돌, 생성 안전성, 30/60/144FPS 일관성, 일시정지, 저장·재시작, 저장소 접근이 차단된 경우의 시작, 전체 진행을 검증합니다.
- `npm run test:run`: 체력·공격력 보정이나 적 강제 제거 없이 입력을 선택하는 자동 플레이입니다. 시드 123에서 **9개 방, 122명 처치, 약 12분 56초의 게임 시간으로 승리**했습니다. 실행 자체는 렌더링 없는 시뮬레이션이라 빠르게 끝납니다.

브라우저 통합 검증은 Python Playwright와 `/usr/bin/chromium`이 설치된 환경에서 서버를 먼저 실행한 뒤 수행합니다.

```sh
GAME_URL=http://127.0.0.1:8000 npm run test:browser
```

단일 HTML은 다음과 같이 브라우저에 문서를 직접 공급하고 오프라인 상태에서 동일한 기능을 검증할 수 있습니다. 이 주소는 테스트가 가로채므로 실제 서버나 DNS 연결을 사용하지 않습니다.

```sh
GAME_HTML=dist/index.html GAME_URL=http://standalone.test/ npm run test:browser
```

검증 환경의 관리 Chromium은 `file://` 탐색을 정책으로 차단하므로 실제 더블클릭 방식은 직접 검증하지 못했습니다. 정책 변경 없이 단일 HTML을 직접 공급하는 방식으로 검증했습니다. 일반 브라우저의 로컬 파일 실행에 필요한 외부 리소스나 모듈 가져오기는 없습니다.

실제 키보드·마우스로 이동, 점프, 사격·명중·처치, 재장전, 획득, 교체, 회피, 슬로모션을 확인합니다. 이후 방 전환·보상·보스·승패 화면은 가속된 전투 상태로 확인합니다. 브라우저 오류 0건, 외부 네트워크 요청 0건을 확인했습니다. 스크린샷은 기본 `/tmp/last-bullet-artifacts`에 저장됩니다.

**검증 한계:** 사람의 실시간 10~15분 수동 완주·장기 난도 조정, 실제 스피커 청음, Firefox/Safari 및 모바일 터치 조작은 검증하지 않았습니다. PC 키보드/마우스가 대상이며, 요청한 게임 요소 중 별도로 미구현한 항목은 없습니다. 10~15분은 설계 목표이고 숙련도와 강화 조합에 따라 달라집니다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 더블클릭 실행·정적 배포용 단일 HTML |
| `scripts/build.mjs` | 외부 패키지 없는 단일 파일 생성 |
| `scripts/deploy.mjs` | GitHub Pages 배포 브랜치 갱신 |
| `index.html`, `styles.css` | 한국어 화면과 반응형 레이아웃 |
| `src/main.js` | 초기화, 단일 입력 연결, 프레임 루프 |
| `src/game.js` | 물리·전투·AI·강화·진행·저장 |
| `src/data.js` | 무기·적·강화 수치, 구역·방 생성 |
| `src/render.js` | 도트 스프라이트·저해상도 렌더링, 다층 배경, 비·안개·효과 |
| `src/audio.js` | 절차적 음악·효과음과 볼륨 |
| `src/ui.js` | HUD, 메뉴, 설정, 강화와 승패 화면 |
| `tests/` | 로직·브라우저·전체 자동 플레이 검증 |
